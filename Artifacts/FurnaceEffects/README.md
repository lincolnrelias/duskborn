# Furnace effects implementation — 2026-09-25

## Scene furnace repair

The furnace already placed in `SampleScene` was a plain `Workbench` prefab instance. It bypassed `BuildingWorld.Create`, so it had neither a `PlacedBuilding` processing state nor an attached operating effect, and interaction opened the older crafting UI. `BuildingWorld` now registers existing furnaces in its scene (including inactive network scene objects), preserves their location, assigns stable scene-hierarchy IDs, and attaches the same effect used by constructed furnaces. Snapshots update these instances rather than creating duplicates. Untouched scene furnaces still allow loading a checkpoint at session start. Workbench outlines explicitly exclude effect renderers even if the furnace wakes after its effects are attached.

Validation after repair: runtime and furnace editor C# compilation passed; all 40 engine-free processing tests passed. `SceneFurnaceTests` adds 12 Unity integration checks and is included in the CLI test runner, but has not been executed because this project is open in Unity. Visual behavior and real multiplayer remain unverified. Manual check: restart the game session, interact with the scene furnace, load iron and wood, and check for ingot production and fire/smoke. Run `Tools/unity.ps1 all` when the project is closed in the Editor to execute the integration checks.

Implemented in `Assets/_Duskborn/Effects/Furnace/`: reusable effect prefab, five crossed flame ribbons animated by a URP shader, four-frame feathered smoke atlas, three shared materials, coal heat overrides, delayed smoke startup, cooldown, motion clearing, distance culling, and one nearby shadowed light where the renderer supports it. No renderer/exposure/bloom settings or furnace artwork were modified.

`Build_forge.asset` explicitly references the effect. `BuildingWorld.Create` attaches it after initialization and after Workbench caches outline renderers. Restore and late join use that same path. Placement previews only copy the static model and darken its coals/disable its old flames. The effect is separate from the model regenerated by `ForgeModelGenerator`; that generator now also applies the idle appearance to both station prefab variants when run.

`PlacedBuilding.IsProcessing` is a read-only predicate shared with the authoritative processing gates. Paid jobs do not require remaining stored fuel. Output capacity, valid recipe/output, and positive finite speed gate progress. Eligible consecutive slotted jobs stay operating at exact completion boundaries. No snapshot schema changed, and clients do not advance jobs. Repeated snapshots do not restart effects.

The anchor fitting uses the actual imported static-flame and shell renderer bounds at attachment; the authored anchor transforms can instead be used by disabling `fitAnchorsToModel`. Offline inspection of the FBX confirms separate Furnace_Flames and Furnace_Coals meshes, a flame base at 0.84 m, arch crown about 1.53 m, and shell top at 2.30 m. The imported orientation and final visual fit still require live inspection.
